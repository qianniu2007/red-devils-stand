About Red Devils Stand

This is the personal project for the Web Technologies course, and the first time I’ve built a site around something I genuinely love.

Why this site

Instead of another tutorial, I made something I care about

My first version was an “HTML/CSS/JS study notes” site, a topic that heavily overlapped with the course itself, and it was almost entirely produced in one go with a single prompt, with no ideas of my own. After the problem was pointed out, I looked back and had to agree.

So this time I changed direction: I’m a United fan, so I built a fan site that actually works. I checked the hard content — fixtures, squad, history — against public sources one by one, and the match notes are entirely my own real writing; the tool only helps me organize and implement it as a webpage, never to write my opinions for me.

I didn’t use any framework or template — just plain HTML, CSS and JavaScript, committed in stages as I built it, so the version history shows a site that grew step by step rather than appearing in one shot.

Sources: public fixtures, squad and honours information from manutd.com and premierleague.com, compiled in November 2026. This is an unofficial learning project with no official link to the club.

Tech stack and implementation

  • Page structureSemantic HTML5
  • StylingHand-written CSS, Flexbox/Grid
  • InteractivityVanilla JavaScript
  • Data storageStatic data + localStorage
  • Version controlGit, staged commits
  • HostingGitHub Pages
  • Frameworks/librariesNone, all vanilla
  • Backend/databaseNone
